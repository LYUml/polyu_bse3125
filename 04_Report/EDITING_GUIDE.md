# 小组文字修改说明

请修改同目录的 `Report_Text_For_Editing.md`。它包含当前最终报告的全部正文、图注、文字表格及参考文献，不嵌入图片。原始 DIALux 输出和附录保持在 PDF 中。

- 可以修改英文表达、解释、标题、图注及参考文献。
- 保留章节编号、Figure/Table 编号及引用编号，方便更新回现有排版。
- 计算结果、灯具数量、功率、尺寸及假设如需改变，请在旁边写 `TODO: 原因/建议`，不要直接把新数值当作已验证结果。
- 新增来源请附完整网址及希望支持的句子。
- 建议新增或讨论的内容用 `<!-- COMMENT: ... -->` 标注；这些评论不会放入 PDF。
- 修改后把这份 Markdown 交回，由助手核对变化、同步报告源数据并重新排版、检查页数与图表。当前 PDF 不会因编辑 Markdown 自动改变。

请尽量保持长度接近现有文字，以便正文含 CAD 继续控制在 9 页。无需学习 LaTeX 或 Python。
