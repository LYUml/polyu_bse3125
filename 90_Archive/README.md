# Historical files

`Development` contains old reports, native model trials, full earlier exports, screenshots, execution sessions and historical scripts. `Documentation` preserves the pre-reorganization project/readme documents. These files are retained for traceability, not offered as the final submission.

Names such as Final_v01-v04 and draft/native version numbers describe historical checkpoints. Current files are identified by the root README and `03_Engineering/project-index.json`. Archived scripts and evidence may contain former paths; `05_Calculations/workspace-migration.json` maps them to current locations. The current report rebuild does not depend on this archive.

No old model, simulation evidence or private draft was deleted during organization. Large/private archive contents remain local; only already tracked historical material is retained in Git.
