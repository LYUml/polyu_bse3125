# Final handover

The course submission is the single PDF in this directory. The DIALux folder contains the editable project handover.

- `BSE3125_Lighting_Design_Report.pdf`: the combined report, formal lighting layout and simulation appendix (26 pages, 7.17 MB).
- `DIALux/Final/Office_Workstations.evo`: main final design; desk illuminance, uniformity and directional UGR.
- `DIALux/Final/Office_Visual_Environment.evo`: matching final design; cylindrical, surrounding, background, wall and ceiling evaluations.
- `DIALux/Comparisons`: three sensitivity studies, each with workstation and visual-environment models. `Output90` reduces scene output to 90%; `Lower_Reflectance` uses 70/50/20% finishes at full output; `Combined` applies both changes.

Start with `Office_Workstations.evo`. The auxiliary file evaluates the same lighting design with additional calculation surfaces; it is not a competing design. All eight native files match the verified saved/reopened originals byte-for-byte. The complete raw calculation reports and editable CAD remain in `03_Engineering`.

These are local handover files. No Blackboard upload has been performed.
